# RLbasix

A collection of reinforcement learning baseline scripts demonstrating various RL algorithms, including:

- **Model-Based RL (Dyna-Q)**
- **Model-Free RL (Q-Learning)**
- **On-Policy RL (SARSA)**
- **Off-Policy RL (Deep Q-Network)**
- **Continuous State & Action Spaces with DDPG**

Feel free to explore and experiment with the code!
